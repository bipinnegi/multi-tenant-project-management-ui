# 🎨 Project Management UI  
### Angular | TypeScript | REST API Integration

A **modern frontend application** built to consume and interact with a **secure ASP.NET Core REST API**.  
This UI provides an intuitive interface for **project and task management**, following clean UI practices and real-world frontend architecture.

---

## 🧠 Overview

This project serves as the **frontend layer** for the Project Management system.  
It communicates with the backend via **REST APIs**, handles authentication, and provides a smooth user experience for managing projects and tasks.

The application is designed to reflect **industry-standard frontend development practices**, not just basic UI screens.

---

## ✨ Features

- 🔐 Authentication-based UI flow
- 📁 Project Management (View / Create / Update / Delete)
- ✅ Task Management within projects
- 🔄 REST API integration with ASP.NET Core backend
- 📡 Secure API communication using tokens
- 🧩 Component-based architecture
- 🎨 Clean and responsive UI
